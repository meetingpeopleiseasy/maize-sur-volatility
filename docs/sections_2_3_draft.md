# 第 2 部分：数据处理、计量分析与识别（构思稿）

本稿基于仓库中 `ppj_1.py` 至 `ppj_6.py` 与 `pj_3test.py` 的现有口径整理。主口径为 `CHRIS-CME_C1.csv` 构造的季度已实现波动率，该口径的回归结果尚待补齐；`rangedata_commodities_since1877.csv` 的日度区间作为替代口径，下面给出的数字为已跑出的探索性结果，用于判断哪些结论是设定依赖的。

## 2.1 数据获取、频率转换、时间匹配与缺失值

库存数据取自 `feed-grains-yearbook-all-years.xlsx` 的 `FGYearbookTable04`（玉米供需平衡表）。营销年度字段向下填充，只保留 Q1--Q4 行，`Total use` 与 `Ending stocks` 转为数值并删除缺失。每个营销年度的年度使用量为四季度使用量之和；由于文件没有逐期发布日期，库存观测是当前版本数据，而非交易者可实时获得的旧版本数据。

价格主口径为玉米连续合约的日度结算价。先取对数差分得到日收益率，再识别换月异常收益并将其置零，随后按营销年度--季度聚合。季度有效标准初步为交易天数不少于 55 天，不足的季度剔除。替代口径使用日度价格区间 F1、F2，按营销年度--季度聚合，并只保留覆盖三个完整自然月的季度。

时间匹配以“营销年度 + 季度”为键。营销年度自 9 月开始：9--11 月为 Q1，12--2 月为 Q2，3--5 月为 Q3，6--8 月为 Q4。此前脚本曾以 8 月为分界，`ppj_4.py` 已修正为 9 月分界，写入正文时以修正后的口径为准。

## 2.2 变量构造

库存使用比定义为：

$$\mathrm{SUR}_{t} = \frac{\mathrm{Ending\;stocks}_{t}}{\mathrm{Annual\;use}_{t}},\qquad \mathrm{Annual\;use}_{t}=\sum_{q} \mathrm{Total\;use}_{t,q}.$$

回归采用滞后一期 $\mathrm{SUR}_{t-1}$，以削弱同期反馈。价格变量为对数收益 $r_d=\Delta\ln \mathrm{Settle}_d$，季度已实现波动率为 $\mathrm{RV}_{q}=\sqrt{\sum_{d\in q}r_d^2}$；区间口径下，因变量取季度内日均价格区间，作为波动率的低频替代。

## 2.3 基准模型与主要结果

基准模型为：

$$\mathrm{Vol}_{q}=\alpha+\beta\,\mathrm{SUR}_{q-1}+X_q'\gamma+\varepsilon_q,$$

其中 $\mathrm{Vol}_q$ 为 $\mathrm{RV}_q$ 或日均区间，$X_q$ 依次加入季度固定效应、线性时间趋势与滞后因变量，标准误采用异方差自相关稳健形式。理论预期 $\beta<0$：库存越紧，波动率越高。

区间口径的探索性结果显示，线性关系对去趋势和滞后项非常敏感。只控制季度固定效应时，$\beta$ 为负且边际显著（F1 约 $-0.0105$，$p\approx0.037$；F2 约 $-0.0119$，$p\approx0.011$）；加入线性趋势与滞后因变量后，系数转为正且不显著（约 $+0.0017$ 与 $+0.0013$，$t<1$）。一阶差分模型中 $\Delta\mathrm{SUR}$ 的系数为正且接近显著（F1 约 $+0.013$，$t\approx2.0$）。这意味着原始负相关主要来自共同趋势，而非库存缓冲机制。

主口径 `CHRIS-CME_C1` 应报告同一组行：仅季节固定效应、加趋势、加滞后因变量、二次项、阈值设定、一阶差分，并把系数符号是否随去趋势翻转作为核心判读点。

## 2.4 季节性控制、滞后项、分位数与高波动状态

库存与价格波动都有强季节性。区间口径下，季度固定效应对 SUR 的 $R^2$ 约 $0.77$，对区间的 $R^2$ 约 $0.11$；SUR 去季节后 AR(1) 约 $0.91$，区间 AR(1) 约 $0.73$。季节性可通过季度或月度固定效应、STL 去季节化以及“季节 $\times$ SUR”交互项处理，但引入方式会改变系数，应作为设定稳健性报告。

滞后项方面，滞后因变量吸收了大部分持续性，加入后 SUR 系数显著变化，因此基准模型不能省略滞后因变量，也应区分当期与滞后 SUR。分位数与阈值设定应避免事后挑选断点。区间口径的阈值点估计约在 SUR $=0.48$ 附近，但 sup-F 检验的 bootstrap $p\approx0.24$--$0.28$，不显著；二次项也不显著，而样条联合检验显著，说明非线性形状不稳定，不能简单写成“低库存才推高波动”。

高波动状态可定义为波动率上尾（如前 10% 或前 1%）并检验其与低库存的共现。需要同时报告缩尾、剔除上尾与 Cook 距离影响，避免少数极端年份决定结论。

## 2.5 重点：识别假设、模型设定与结果的冲突

第一，SUR 不是交易者可实时观测的变量。分母使用全营销年度的实际使用量，在季度 $t$ 尚未可知，存在前视偏差；用 $\mathrm{SUR}_{t-1}$ 并不能消除这一偏差。第二，库存与波动率都有共同趋势，水平回归的负相关在去趋势后消失甚至转正，说明基准结果可能由趋势共同运动驱动。第三，反向回归中滞后区间对 SUR 有预测力，说明存在反馈或共同状态，不能把 SUR 当作外生。第四，连续合约的换月处理会把换月跳变误记为波动，库存又是季度聚合，时间匹配较粗。第五，样本量小，阈值和结构断点检验功效低，容易过拟合。以上冲突决定了本文至多能主张“历史条件相关”，不能主张库存对波动的因果缓冲效应。

# 第 3 部分：结果、可视化与研究反思（构思稿）

## 3.1 两张核心图

描述性图：同一时间轴上的 SUR 与波动率，左轴为 SUR、右轴为 RV 或日均区间，标出 1996 年《农业法案》与 2006 年乙醇政策节点，直观展示两者在趋势层面反向运动、在去趋势后关系变弱。

系数对比图：将不同设定下的 SUR 系数及置信区间并列——仅季节固定效应、加趋势、加滞后因变量、二次项、样条、阈值、一阶差分、分时期子样本。该图比表格更能说明“符号与显著性随设定翻转”。

## 3.2 主要发现

较稳健的结论是：库存与波动率都有强季节性、高持续性；原始水平上两者负相关；区间口径存在 2003/04 年前后的结构变化。较敏感的结论是：SUR 系数的符号与显著性高度依赖去趋势、滞后因变量和波动率口径；阈值效应不显著；分时期子样本的斜率差异较大。因此，正文应将稳健部分与设定敏感部分分开表述，避免只报告一个“好看”的设定。

## 3.3 局限

库存指标与价格的时间匹配较粗，SUR 分母存在前视偏差，文件缺少逐期版本；季节性处理方式多样且影响结论；季度样本量有限，结构变化与阈值推断功效不足；库存由供需共同决定，内生性使系数无法直接解释为因果缓冲效应；连续合约换月处理与波动率口径尚未最终确定。

## 3.4 下一步：重新设计而非继续堆稳健性

优先重新构造库存变量：改用滞后的年度使用量或分季度预测使用量作为分母，并尽可能找到带发布日期的历史版本，使 SUR 成为交易者当季可知的前定变量。其次，确定波动率口径并固定换月规则，减少口径自由度。然后转向识别策略，例如利用天气或政策造成的供给冲击作为库存变化的外生来源，或在 WASDE 发布日做事件研究，直接检验“库存信息冲击是否放大波动”。在完成这些重新设计之前，不宜继续增加稳健性回归，因为目前的核心不确定来自测量与识别，而不是设定选择的细节。
